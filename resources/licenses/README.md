# Bundled license files

These files accompany packaged applications:

- `Apache-2.0.txt` covers Apache-licensed MediaPipe runtime/model assets.
- `FFmpeg-GPL-3.0.txt`, `FFmpeg-BUILD-LICENSES.txt`, and `FFmpeg-README.txt` come from the installed
  `ffmpeg-static` package and describe the bundled executable and corresponding-source information.

Regenerate or copy the FFmpeg files from the exact locked dependency version when that dependency is
updated.
